# Шақырудың әуені / Музыка для приглашения

Тұсаукесер шақыруының фондық әуенін осы бумаға салыңыз.

**Файлдың аты:** `tusaukeser.mp3`

Яғни толық жолы — `public/music/tusaukeser.mp3`.

---

## Как добавить музыку

1. Положите свой mp3-файл в эту папку и назовите его `tusaukeser.mp3`.
2. Всё — страница подхватит его сама, ничего в коде менять не нужно.

Если файл лежит под другим именем, поправьте одну строку в
`app/tusaukeser/invite-config.ts`:

```ts
music: {
  src: "/music/ваш-файл.mp3",
  title: "Мерекелік әуен",
},
```

### Пока файла нет

Ничего не ломается: кнопка «Шақыруды ашу» работает как обычно и открывает
приглашение, просто без звука, а круглая кнопка плеера в углу не показывается.

### О чём стоит помнить

- Браузеры не дают включить звук сами по себе — только после нажатия. Поэтому
  музыка и стартует с кнопки «Шақыруды ашу».
- Файл весит столько же, сколько и грузится: для телефонов лучше держать его в
  пределах 2–4 МБ (примерно 2–3 минуты в 128 kbps). Трек зациклен, так что
  длинный файл не нужен.
- Выкладывайте только ту музыку, которую имеете право использовать.
